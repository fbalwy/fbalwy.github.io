**Work package:** BRD-002 v1  
**Evidence date:** 18 August 2026 (Asia/Riyadh)  
**Status:** Complete evidence extraction for Gate G0; not an approval, asset audit, co-branding model, token set, design, derivative, or deployment decision  
**Website context:** English-only personal academic website for Faisal Albalwy; not an official Taibah University portal

## 1. Scope, authority, and citation method

This record accounts for all 78 rendered pages of `الدليل الارشادي للهوية البصرية.pdf` and extracts the identity evidence applicable to a website. The guide was reviewed from page renders as well as extracted text. The protected English horizontal logo master, the supplied white English logo export, the three-page A4 template, and the supplied font-license files were used only to clarify application. No source asset was modified.

Source precedence is fixed as follows:

1. An explicit written rule in the guide.
2. An official supplied vector master.
3. A production template that consistently demonstrates the guide.
4. A raster export or sampled asset characteristic.
5. A website-specific interpretation.

Citation form is `Guide p. N / PDF N` when a visible printed folio exists. Pages 1-4, 15, and 41-78 do not display a folio; they are cited as `Unfolioed / PDF N`. The contents page assigns the application sequence beginning at 42, but this record does not present those inferred sequence numbers as visible printed folios. English paraphrases are used throughout.

Every finding is classified:

| Classification | Meaning in this record |
|---|---|
| **Direct** | Written in the guide, visibly specified by a guide example, or explicitly stated by a cited supplied license/source. A visual example is labelled as such and is not silently converted into a universal mandate. |
| **Derived** | A necessary web interpretation that preserves direct evidence without claiming the guide says it. |
| **Proposed** | A website-specific project decision. A locked owner decision can be final for this project while still not being an institutional rule. |
| **Unresolved** | The supplied evidence does not support a safe conclusion. |
