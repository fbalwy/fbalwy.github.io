# Research

My research examines trustworthy digital systems: how sensitive data can be shared with stronger privacy controls, how decentralized systems can exchange information securely, and how machine learning can support cyber-threat detection. The themes below describe recurring areas in the verified publication record; they do not imply deployment, adoption, funding, or measured impact.

## Privacy-preserving health-data sharing

This theme brings together work on dynamic consent for clinical genomic data, zero-knowledge policy enforcement for cross-institutional health records, and secure federated analysis of sensitive healthcare data.

The work considers how consent, access policies, encryption, and distributed computation can support data use while limiting unnecessary disclosure.

[View related publications](/publications)

## Blockchain security and interoperability

This theme examines blockchain and smart-contract mechanisms for secure exchange across heterogeneous systems. The publication record includes data standardisation between blockchain platforms and blockchain-supported security for communication between software-defined network controllers.

[View related publications](/publications)

## Machine learning for cyber-threat detection

This theme examines machine-learning and deep-learning methods used in intrusion and phishing detection. The work includes a broad survey of intrusion-detection strategies and studies of feature selection and deep learning in connected-device environments.

[View related publications](/publications)
